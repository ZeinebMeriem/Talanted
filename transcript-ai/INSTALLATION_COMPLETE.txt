🚀 QUICK START OPTIONS:

Option 1: Add OpenAI API Key (for API mode)
──────────────────────────────────────────────
1. Get an API key from: https://platform.openai.com/api-keys

2. Add to .env file:
   echo 'OPENAI_API_KEY=sk-your_key_here' >> .env

3. Run the quick launcher:
   python quick_start.py

4. Or use full program:
   python main.py --api --record --duration 10


Option 2: Install Local Whisper Model (no API key needed)
──────────────────────────────────────────────────────────
1. Install additional packages:
   pip install torch torchaudio openai-whisper

2. Run without API flag:
   python main.py --record --duration 10

Note: This downloads ~2GB and takes 5-10 minutes


Option 3: Test with Existing Audio Files
────────────────────────────────────────────
If you have an audio file, you can test right away:

   python main.py --api --file /path/to/audio.wav

📝 AVAILABLE COMMANDS:

Activate Virtual Environment:
   source venv/bin/activate

Quick Launcher (API mode):
   python quick_start.py

Full Interactive Mode:
   python main.py              # Uses local model
   python main.py --api        # Uses OpenAI API

Record and Transcribe:
   python main.py --api --record --duration 10 --language ar

Transcribe File:
   python main.py --api --file audio.wav --language fr --save

Examples:
   python examples.py

Test Setup:
   python test_setup.py

Help:
   python main.py --help

   ✅ Tunisian Dialect (tn)  - python main.py --language ar
